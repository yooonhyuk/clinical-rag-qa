# 007. 근거를 인용한 부분 답변이 `insufficient_evidence=true` 때문에 거절로 처리됨 (교차 문서 질문의 오거절)

- 상태: 미해결 (원인 분석, 수정 방향 정리)
- GitHub: https://github.com/yooonhyuk/clinical-rag-qa/issues/8
- 발견: 2026-10-07, 공개 코퍼스 첫 평가(gemma4:e4b)
- 영향 범위: MODEL_REFUSED 판정, 교차 문서·교차 언어 질문의 False refusal
- 관련 코드: `backend/app/services/rag_service.py`(`_generate`), `backend/app/prompts/rag_prompt.txt`

## 증상

답이 있는 79문항 중 12문항(15.2%, 벡터 단독)이 모두 MODEL_REFUSED로 거절됐습니다. 교차 문서 유형은 7문항 중 4문항(57.1%), 하이브리드에서는 5문항(71.4%)입니다. 이 중 여러 건은 모델이 **정답을 인용과 함께 썼지만** 앞부분에 "문서에서 확인할 수 없습니다 / 직접적인 비교 정보는 없습니다"라고 단서를 달고 `insufficient_evidence=true`를 반환했습니다.

| 문항 | 유형 | 검색 | 모델 답변(요약) |
|---|---|---|---|
| p49 | iRECIST의 hyperprogression 정의 | 정답 섹션 포함 | "구체적인 내용은 없습니다. 다만 … 치료 전 대비 종양 성장 동역학이 2배 이상 증가 [2]" → **정답인데 거절 처리** |
| p31 | 식약처·EMA 재투여 최소 주기 비교 | 두 문서 모두 포함 | "명확하게 비교하지 않습니다. 다만 … 동일 용량으로 최소 2주기 이상 [1]" → 한쪽 문서만 근거로 정답 |
| p84 | iRECIST·RANO 2.0 확인 스캔 시점 | RANO만 포함 | RANO 부분(4주 또는 8주 후) 정답, iRECIST 부분은 근거 없음 |
| p85 | RECIL·RANO 2.0 minor response 비교 | 두 문서 포함, RECIL 정의 섹션 누락 | 일부만 답함 |

`RagService._generate`는 `insufficient_evidence`가 참이면 인용이 있어도 거절로 바꿉니다. 그래서 "일부 근거로 일부 답한" 경우와 "근거가 전혀 없는" 경우가 같은 MODEL_REFUSED로 기록됩니다.

## 원인

1. **응답 스키마가 이분법입니다.** `insufficient_evidence`가 참/거짓 하나뿐이라, 모델이 비교 질문의 한쪽만 근거가 있으면 "부족"으로 표시합니다.
2. **교차 문서 질문의 top-5에 두 문서가 다 들어오지 않습니다.** p84는 RANO chunk만 5개였습니다. top-k에 문서 다양성이 없습니다(이슈 006과 같은 원인).
3. **소형 생성 모델(gemma4:e4b)의 보수적 단서.** 근거가 충분한 p49에서도 "구체적인 내용은 없다"로 시작했습니다. 우연이 아닙니다. 같은 설정(temperature 0.1)으로 두 번 실행했을 때 거절된 12문항이 완전히 같았습니다(`..._public_bge-m3-vector-gemma4-e4b-run2_...`).

## 수정 방향 (다음 단계)

- 응답 스키마에 `partial`(일부 근거) 상태를 추가하고, 인용이 있는 부분 답변은 "부분 답변"으로 반환해 거절과 구분한다. 평가 지표에도 부분 답변을 따로 센다.
- 비교·교차 문서 질문은 문서별로 검색해 각 문서의 근거를 프롬프트에 넣는다(질문 분해 또는 문서당 상한).
- 프롬프트에서 "질문의 일부에만 근거가 있으면 근거가 있는 부분만 답하고 나머지는 확인할 수 없다고 쓰라"고 지시한다.
- 생성 모델 비교(다음 단계, medgemma:4b 등)에서 같은 문항의 거절률을 비교한다.
